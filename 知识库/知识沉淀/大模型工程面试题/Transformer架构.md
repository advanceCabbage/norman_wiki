## 一、RNN
**RNN -> Recurrent Neural Network**（循环神经网络）
Transform 出现之前，处理数据的主流方法是 RNN，RNN 存在两个致命问题。
- **第一个是顺序计算，无法并行**，RNN 处理序列的方式是从左到右逐个处理每个词，第 N 步必须等第 N-1 步计算完成才能开始，无法利用 GPU 的并行计算能力，这导致训练大型 RNN 极慢
- **第二个是长距离梯度消失**，例如无法记住第一个词与第 1000 个词之间的关系

## 二、Transformer
2017 年谷歌在论文《Attention is All You Need》中提出了 Transformer，用 Transformer 架构解决了上述两个问题。

Transformer 常见的三种架构
- **Encoder-only(以 BERT 为代表)**：每个 Token 可以双向关注序列中其他 Token。双向理解能力让 Encoder 擅长「理解任务」，比如文本分类、语义相似度计算
- **Decoder-only（以 GPT/Claude/Qwen 为代表）**：使用因果掩码，每个 Token 只能关注它前面的 Token，不能「提前看到」后面的内容。单向设计天然适合文本生成
- **Encoder-Decoder（以 T5 为代表）**：Encoder 双向理解输入，Decoder 单向生成输出。适合「输入和输出是不同的文本」任务，比如：翻译、摘要等。

**为什么通用生成式大模型大多选择 Decoder-only？**
- **目标统一**：所有任务类型（问答、写作、推理）都可以统一表达成「续写」这一件事，不需要区分这是理解任务还是生成任务，一套训练目标搞定一切
- **海量数据自监督训练**：互联网大量公开的数据均可作为训练数据，无需人工标注
- **能力涌现**：随着模型规模增大，模型涌现能力越来越强，模型会自动学会数学、推理、跨语言迁移等能力。这都是「预测下一个 Token」这个目标在足够大规模下自然的涌现
## 三、Transformer 架构包含哪些内容
#### 3.1 Self-Attention 自注意力机制
**核心思路**：让序列中每个 Token 都能直接关注序列中任意其他位置的 token，计算出「当前 token 和其他位置的相关程度」，然后根据相关程度加权聚合其他位置的信息

**三个关键向量**：
- Q（Query，查询）：代表「想找什么内容」
- K（Key，键）：代表「我有什么标签」
- V（Value，值）：代表「我的实际内容」
Self-Attention 自己由什么组成
- **Q/K/V**：被 Self-Attention 计算过程包含的三个中间变量，其实 Q/K/V 不是模型「凭空生成」的，而是把输入 embedding 通过**三个独立的线性投影矩阵**
- **缩放点积**：Self-Attention 内部的数值稳定化技巧

解决 RNN 两个问题：
- 解**计算无法并行** 靠：矩阵化并行计算——所有 token 的 Q/K/V 能同时算，不用排队
- 解**长距离梯度消息** 靠：任意两个 token 直接点积计算，路径长度是 O(1)，不会因为距离远而衰减

#### 3.2 Multi-Head Attention 多头注意力机制
单组 Q/K/V 只能学习到一种「关联关系」，但语言中的关联是多维度的。
Multi-Head Attention 就是把 Q/K/V 投影到多个不同子空间，每组独立计算注意力，最后把所有头输出拼接起来。每个头可以专注于捕捉不同类型的语言关联，整体上表达能力更强

#### 3.3 Feed-Foward Network 前馈网路
每个 Transformer 块里还有一个前馈网络（Feed-Forward Network）
FFN 对每个位置独立地做非线性变换，补充注意力层学不到的信息（**注意力层本质上是线性加权，FFN 引入非线性**）。研究表明 FFN 层储存了大量的「事实知识」，可以理解为模型的「记忆仓库」

#### 3.4 位置编码
不属于 Attention 内部，是外部注入到 Token 上的信息。因为 Self-Attention 有一个天然的缺陷：它的计算是对称的，不考虑词的顺序。所以必须靠位置编码把顺序信息"喂"进去
