## 一、基础款：ReAct 单步迭代范式
**ReAct 本质**：**思考→行动→观察→再思考**的循环范式，规划和执行混在一起，每一步的行动，都基于上一步的结果实时调整，没有提前定死完整计划

## 二、复杂任务款：Plan-and-Execute 规划执行范式
**Plan-and-Execute 本质**：**「规划步骤」和「执行步骤」分开**，可配置两个 Agent 一个专门用于规划步骤，一个用于执行步骤。在成本上可采用贵的模型做规划步骤，便宜的模型做执行步骤。

**优势**：在复杂多步任务上完成准确率通常高于 ReAct，具备完整全局计划兜底，任务执行不容易跑偏

**劣势**：任务计划遇到计划之外的变故时，整体的计划表不能更新和同步调整

**进阶版**：**动态 Replan** 具体做法是每个步骤执行完成后，把当前结果和剩余计划一起交给「规划步骤」模块，让模型继续判断「原本的计划是否需要调整」，需要则重新生成计划，替换原来的计划

## 三、质量增强款：Reflection 反思迭代范式
**Reflection 本质**：是基于 ReAct、Plan-and-Execute 加的「锦上添花」功能，在原本的基础上，加了一层「**自我检查、自我修正**」环节。使得流程变为**生成→评估→改进**

**优势**：能使得输出质量明显提升，幻觉、逻辑错误、细节遗漏都会减少，对严谨性要求高的场景效果尤其明显。

**劣势**：Token 消耗和延迟都会增加，假设没有轮次限制，可能陷入「为了改而改」的死循环

**进阶版**：把每次检查不通过的原因总结为一段「经验教训」，存进记忆里，下次再遇到类似任务时，这段教训会作为上下文传给 LLM，避免重复犯错。进阶版帮助 GPT-4 的 pass@1 （模型只给一次生成机会时的正确率） 准确率从 80% 提升到了 91%。
