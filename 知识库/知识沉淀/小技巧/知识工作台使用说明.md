# 知识工作台使用说明

[[知识库/首页|← 返回知识工作台]]

## 三个入口

- [[知识库/首页|学习与探索]]：学习主线、源码专题、复习计划和调研入口。
- [[知识库/面试与项目|面试与项目]]：面试资料，以及项目实践与面试讲述的对应入口。
- [[知识库/写作与输出|写作与输出]]：原理笔记、原稿、公众号版本和选题素材。
- [[知识库/🗺️ 学习地图|学习地图]]：完整的笔记导航。

顶部三个按钮是普通笔记链接，点击后在 Obsidian 中打开对应入口页。建议用阅读模式浏览工作台，按 `⌘ E` 切换编辑与阅读。

## 启动时打开首页（手动设置）

当前使用的库是 `norman_wiki`（`/Users/haoyang/Documents/项目/norman_wiki`）。

1. 在 Obsidian 设置中搜索“默认”或 `Default file to open`，找到启动时默认打开文件的设置。
2. 选择已有文件，指定 `知识库/首页.md`。
3. 重新打开库，确认出现首页。如果希望随时返回，也可以把首页加入 Obsidian 书签。

不需要为首页另装 Homepage 插件。

## 亮色样式

样式文件位于库根目录的 `.obsidian/snippets/norman-home.css`。

在“设置 → 外观 → CSS 代码片段”中启用 `norman-home`。若列表未出现，点击刷新。

只有带 `cssclasses: [norman-home]` 的入口笔记使用该样式，普通笔记保持原样。三页使用奶油白背景、薄荷绿与奶油黄渐变封面、深绿色文字。窄窗和手机自动转为单栏。封面为 CSS 渐变，不需要下载图片或联网。

## 日常维护

- 修改入口内容：在对应页面按 `⌘ E`，修改 Markdown 链接或描述。
- 更换首页主线：编辑首页“接下来学什么”中的置顶链接。
- 添加新笔记：正常写入现有分类目录，需要显示在学习地图时补一条链接。
- 页面是人工精选导航，不会自动将新笔记插入列表。
- 学习清单与复习计划保留原内容，工作台未推断完成度、截止日期或本周安排。
- 公众号页面按文件与主题关联，“公众号版本”不代表已经发布。

## 恢复

在外观设置中关闭 `norman-home` 即可恢复普通 Markdown 显示。三个入口页仍能作为普通笔记使用。

本次修改前的学习地图和外观设置备份在 `.codex/backups/obsidian-home-20260922/`。恢复外观设置时，优先只关闭本代码片段，避免覆盖之后的其他设置。
